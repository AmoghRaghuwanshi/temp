# 👑 Happy Birthday Mumma — From Her Loving Daughter 🎀

A special, interactive birthday website crafted with endless love and heartfelt memories for **Mumma**, from the perspective of her daughter across the miles.

---

## ✨ Features

- 💌 **Wax-Sealed Surprise Envelope**: Opening animation revealing the special letter with celebratory confetti.
- 📜 **The Golden Parchment Letter**: Heartfelt birthday message preserved with 100% verbatim fidelity, alongside a voice playback feature.
- 🎂 **Virtual Cake Cutting & Candle Ceremony**: Interactive candles that can be blown out and sliced with an animated knife and celebratory toast.
- 📸 **Memories Photo Lane (14 Real Photos)**: Filterable photo gallery with high-resolution lightbox and heart reactions.
- 🫂 **Virtual Hug Machine**: Interactive hold-down hug button featuring gentle heartbeat audio and haptic feedback.
- 🌸 **Love Note Jar**: Randomized daily notes of love and comfort.
- 💬 **WhatsApp Quick Reply**: Direct link allowing Mumma to send a loving reply back.
- 🎵 **Offline Ambient Music**: Ambient lullaby / acoustic melody synthesized natively with the Web Audio API (zero external audio dependencies).

---

## 🚀 GitHub Pages Configuration

This project is configured directly for **GitHub Pages**:
- Root-level `index.html` with relative asset links (`./images/`, `./style.css`, `./script.js`).
- `.nojekyll` included to bypass Jekyll static generator processing.
- Deploy directly from the `main` branch under **Settings > Pages > Deploy from a branch (`main` / `/ (root)`)**.
